# rotate-ai (AutoRotate)

Локальный проект по автоматическому определению и исправлению ориентации изображений (0°, 90°, 180°, 270°) с помощью классификатора на PyTorch.

## 1. Постановка задачи

**Проблема:** фотографии и сканы часто попадают в системы (галереи, документооборот, OCR-пайплайны) повернутыми на случайный угол, кратный 90°, из-за некорректных EXIF-данных или ручной загрузки со сканера/камеры.

**Пользователь:** разработчик или система, которой нужно автоматически нормализовать ориентацию изображений перед показом пользователю или перед подачей в другую модель (например, OCR, детекцию лиц, классификацию).

**Зачем это нужно:** ручная проверка и поворот тысяч изображений — трудозатратная задача. Модель, определяющая угол поворота, позволяет автоматизировать нормализацию изображений в пайплайне обработки данных.

**Задача формализована как классификация на 4 класса**: 0°, 90°, 180°, 270° — модель предсказывает, на какой угол повёрнуто изображение, после чего оно поворачивается обратно.

## 2. Данные

- **Источник:** датасет CIFAR-10 (загружается автоматически через `torchvision.datasets.CIFAR10`), 60 000 цветных изображений 32×32 (50 000 train / 10 000 test).
- **Разметка:** оригинальный датасет не размечен по углам поворота, поэтому разметка генерируется синтетически — каждое изображение случайно поворачивается на 0°/90°/180°/270°, и этот угол становится меткой класса (`RotationDataset` в `train.py`).
- **Классы:** 4 — `0°`, `90°`, `180°`, `270°`, сбалансированы за счёт равновероятной генерации угла (`random.randint(0, 3)`).
- **Разбиение:** train 85% / val 15% от тренировочной части CIFAR-10, отдельный test — тестовая часть CIFAR-10 (10 000 изображений) с фиксированным seed=42 для воспроизводимости.
- **Препроцессинг:** изображения приводятся к размеру 224×224, нормализуются по статистике ImageNet (mean/std), поворот выполняется через `PIL.Image.rotate(angle, expand=True)`.

## 3. Baseline

Простая CNN (`BaselineCNN` в `train.py`) без предобучения: 3 свёрточных блока (Conv-ReLU-MaxPool) + полносвязный классификатор с Dropout. Используется как точка отсчёта, чтобы показать прирост качества от переноса обучения (transfer learning) на предобученных архитектурах.

## 4. Основной подход

Основные модели — предобученные на ImageNet сверточные сети, дообученные под 4-классовую классификацию угла поворота:
- **EfficientNet-B0 (freeze)** — предобученный backbone заморожен, обучается только классификатор.
- **EfficientNet-B0 (full)** — полное дообучение всех весов (`timm`).
- **ResNet-18 (full)** — полное дообучение (`torchvision.models`).

Обучение: AdamW, CosineAnnealingLR, CrossEntropyLoss, лучшая по val accuracy модель сохраняется как чекпоинт (`checkpoints/*.pth`). Инференс инкапсулирован в классе `AutoRotator` (`train.py`/`inference.py`), который предсказывает угол и поворачивает изображение обратно.

## 5. Метрики

Для задачи многоклассовой классификации используются:
- **Accuracy** — доля верно определённых углов поворота.
- **F1-macro** — устойчива к дисбалансу классов (см. `sklearn.metrics.f1_score`).
- **Confusion matrix** — визуализация, какие углы модель путает чаще всего (`plots/03_confusion_matrix.png`).
- **Classification report** (precision/recall/F1 по каждому классу).

Все метрики сохраняются в `results/metrics.json` после каждого запуска обучения.

## 6. Эксперименты

В `train.py` реализовано сравнение 4 моделей на одних и тех же данных:
1. **Baseline CNN** — без предобучения, обучается с нуля.
2. **EfficientNet-B0 (freeze)** — перенос признаков без дообучения backbone.
3. **EfficientNet-B0 (full)** — полное дообучение предобученной сети.
4. **ResNet-18 (full)** — альтернативная архитектура для сравнения.

После обучения выводится сводная таблица (accuracy, F1-macro, число параметров) по всем моделям, а также строятся графики сходимости (`plots/02_training_curves.png`). Запуск: `python train.py --models all --epochs 10`.

## 7. Анализ ошибок

Скрипт автоматически сохраняет визуализацию ошибок лучшей модели (`plots/04_errors.png`, функция `save_error_examples`) — примеры изображений, где предсказанный угол не совпал с истинным, с подписями "Истина / Предсказано". Типичная причина ошибок 180°↔0° и 90°↔270° — низкое разрешение CIFAR-10 (32×32) и симметричные сцены (небо, вода, однородный фон), где визуальных подсказок о верхе/низе недостаточно.

## 8. Выводы

**Получилось:**
- Работающий end-to-end пайплайн: данные → обучение → метрики → инференс.
- Перенос обучения (EfficientNet/ResNet) ожидаемо превосходит Baseline CNN по accuracy и F1.
- Автоматическая коррекция ориентации через `AutoRotator` работает на произвольных изображениях.

**Не получилось / ограничения:**
- Датасет CIFAR-10 низкого разрешения (32×32) — не полностью репрезентативен для реальных фотографий высокого разрешения.
- Синтетическая разметка (случайный поворот) не учитывает реальные искажения (обрезка, EXIF-повороты, шум камеры).

**Что можно улучшить:**
- Дообучить/протестировать на реальном датасете фотографий высокого разрешения.
- Добавить аугментации (яркость, шум) для устойчивости.
- Рассмотреть человеческую оценку (human eval) на выборке реальных фото.

## 9. Код и воспроизводимость

### Структура
- `train.py` — подготовка данных, обучение, сравнение моделей, сохранение метрик и графиков.
- `inference.py` — инференс: предсказание угла и сохранение исправленного изображения.
- `test_device.py` — проверка доступного устройства (Intel XPU / NVIDIA CUDA / Apple MPS / CPU).
- `requirements.txt` — зависимости проекта.
- `setup.ps1`, `setup.bat` — быстрый старт для Windows.

### Установка и запуск
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python test_device.py
python train.py --models efficientnet_full --epochs 10 --batch_size 32
python inference.py -i photo.jpg -o photo_fixed.jpg
```

### Python
Рекомендуемая версия — Python 3.11. Python 3.13 пока не поддерживается PyTorch.

### Установка PyTorch

**Intel Arc / XPU**
```powershell
pip install torch torchvision --index-url https://download.pytorch.org/whl/xpu
```

**NVIDIA CUDA**
```powershell
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
```

**Только CPU**
```powershell
pip install torch torchvision
```

### Обучение
```powershell
python train.py --epochs 10
python train.py --models efficientnet_full --epochs 15 --batch_size 32
python train.py --models all --epochs 15 --batch_size 16
python train.py --skip_train
```

После первого запуска `train.py` проект создаёт директории `data/`, `checkpoints/`, `plots/` и `results/` с артефактами (метрики, графики, чекпоинты).

### Инференс
```powershell
python inference.py -i "C:\Users\You\Pictures\photo.jpg" -o fixed.jpg
```

### Частые проблемы

**PowerShell блокирует активацию окружения**
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

**Не хватает памяти на Intel Arc**
Уменьши `--batch_size` до 16 или 8.

**`timm` не скачивает веса**
Нужен интернет; веса скачиваются один раз и кэшируются локально.
